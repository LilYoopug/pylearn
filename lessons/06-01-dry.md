<learn>
**D.R.Y.** stands for *Don't Repeat Yourself*. If you find yourself writing the
same three lines again, wrap them in a function:

```python
def say_hello():
    print('Hello')

say_hello()
say_hello()
```

`def` introduces the function, the body is indented, and calling it by name
runs the body. Define once, use many times.
</learn>

</instructions>
