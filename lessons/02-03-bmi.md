<learn>
**BMI** (body mass index) is a rough measure that compares weight to height:

```
bmi = weight / height ** 2
```

Note the precedence: `**` binds tighter than `/`, so `height ** 2` is computed
first. Writing `weight / height ** 2` means `weight / (height * height)`.

You can also write `height * height` if that reads more clearly to you — the
result is identical.
</learn>
