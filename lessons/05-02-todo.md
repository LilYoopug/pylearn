<learn>
Lists grow and shrink. Two methods do most of the work:

```python
tasks = ['buy milk']
tasks.append('walk the dog')     # add to the end
tasks.remove('buy milk')         # remove by value
```

`append()` always adds to the **end**. `insert(0, x)` puts something at the
front instead.
</learn>

<instructions>
Start with a list holding one task, `{{first}}`. Then add `{{added}}` to it.

Print the list as a numbered to-do:

```output
1. {{first}}
2. {{added}}
```

Use `enumerate()` so the numbering comes from the loop, not from hardcoded
numbers.
</instructions>

<help>
<hint>`enumerate(tasks, start=1)` gives you the number and the item together.</hint>
<solution>
tasks = ['{{first}}']
tasks.append('{{added}}')
for number, task in enumerate(tasks, start=1):
    print(f'{number}. {task}')
</solution>
</help>
