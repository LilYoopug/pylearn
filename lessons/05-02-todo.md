<learn>
`enumerate()` memberi kamu nomor urut sekaligus elemennya.

```python
for i, item in enumerate(items):
    print(i + 1, item)
```

Karena `enumerate()` mulai dari 0, tambahkan 1 supaya penomorannya wajar.
</learn>

<instructions>
Mulai dengan list berisi satu tugas, `{{first}}`. Lalu tambahkan `{{added}}`
ke dalamnya.

Cetak list itu sebagai daftar tugas bernomor:

```output
1. {{first}}
2. {{added}}
```

Gunakan `enumerate()` supaya penomorannya berasal dari loop, bukan angka yang
ditulis manual.
</instructions>

<help>
<hint>Pakai `append()` untuk menambah tugas, lalu `enumerate()` untuk memberi nomor.</hint>
<solution>
tasks = ['{{first}}']
tasks.append('{{added}}')
for number, task in enumerate(tasks, start=1):
    print(f'{number}. {task}')
</solution>
</help>
